# AI/ML Internship - Task Submission Repository

Welcome to my AI/ML Internship repository. This project contains a collection of tasks focused on Data Science, Exploratory Data Analysis (EDA), and Machine Learning modeling. Each task demonstrates a complete workflow from data cleaning to model evaluation.

## 🚀 Repository Overview
This repository serves as a portfolio of my work during the internship. It covers various domains including healthcare, finance, botany, and real estate, utilizing industry-standard Python libraries.

---

## 📂 Tasks Summary

### Task 1: Iris Flower Exploratory Data Analysis
* **Goal:** Analyze the physical characteristics of Iris flowers to determine the most significant features for species classification.
* **Key Techniques:** Data Visualization (Scatter, Pair, Histogram, Box plots), Statistical Summary.
* **Insights:** Discovered that Petal measurements are significantly stronger predictors for species identification than Sepal measurements.

### Task 2: Apple (AAPL) Stock Price Prediction
* **Goal:** Forecast the next day's closing price for Apple Inc. based on historical market trends.
* **Key Techniques:** Time-series data engineering (`shift`), Feature Scaling, Linear Regression, Random Forest Regressor.
* **Insights:** Successfully captured stock price trends by using chronological data splitting and identifying the impact of daily volume on price movement.

### Task 3: Heart Disease Classification & Data Cleaning
* **Goal:** Predict the presence of heart disease using clinical patient data while ensuring high data quality.
* **Key Techniques:** IQR-based Outlier Handling, One-Hot Encoding, Logistic Regression, Decision Tree Classification.
* **Insights:** Improved model reliability by capping extreme outliers in Blood Pressure and Cholesterol measurements.

### Task 6: Housing Price Prediction (Advanced Pipeline)
* **Goal:** Estimate property values using a robust machine learning pipeline.
* **Key Techniques:** Scikit-learn `Pipelines`, `ColumnTransformer`, One-Hot Encoding, Feature Importance analysis.
* **Insights:** Identified "Area" and "Bathrooms" as the primary drivers of house prices. The use of Pipelines ensured clean, reproducible, and modular code.

## 📈 Methodology
For every task, I followed a structured 5-step process:
1. **Problem Definition:** Establishing the core goal and target variable.
2. **Data Preprocessing:** Cleaning, handling missing values/duplicates, and scaling.
3. **Exploratory Data Analysis (EDA):** Visualizing patterns and correlations.
4. **Model Development:** Training multiple algorithms to find the best fit.
5. **Evaluation:** Assessing performance using metrics like Accuracy, MAE, and RMSE.
